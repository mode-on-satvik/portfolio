# robots.txt — crawl policy
#
# Two separate goals here, and they need different rules:
#
#   1. Search engines SHOULD index the portfolio. That is the entire point of
#      a public casting site.
#   2. AI training crawlers should NOT. A five-year-old's photographs do not
#      belong in a training corpus, and the <meta name="robots"
#      content="noai, noimageai"> tags say the same thing in-page.
#
# Honoured on the honour system: these directives are voluntary and a crawler
# that ignores robots.txt will ignore this file too. Stated plainly rather
# than pretended away — this reduces exposure, it does not prevent scraping.

# --- Search engines: welcome, except the admin panel ------------------------

Disallow: /tools/

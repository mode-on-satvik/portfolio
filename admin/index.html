Paste your GitHub access token. It is kept in this tab's memory only — never saved to the device — so you will need it again after a reload.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens and choose Generate new token.
  2. Under Repository access pick mode-on-satvik/portfolio only.
  3. Under Permissions → Repository set Contents to Read and write.
  4. Set an expiry you are comfortable with, generate it, and copy the value — GitHub shows it once.
